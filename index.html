Rumus Perhitungan Poin Hybrid Margin System

Total Poin = Base Poin (Win) + Diff Point + Game Point
1. Base Poin (Win %):
Murni dari persentase kemenangan (100% = 100 Poin).
2. Diff Point:
Poin Selisih Skor:
(Tot Diff × 0.15) +
(Avg Diff × 2.0)
3. Game Point:
Margin Linear - Penalti Inaktif
*Margin Linear: Selisih dr rata-rata × 0.20 (Game > 24 × 0.10).
*Penalti Inaktif: Dipotong 10% dari Win Rate per bulan absen/tidak main.
